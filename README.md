# MyHome

サークルの引き継ぎアプリです。

## 開発

Node.js 22.12 以上（または 20.19 以上の Node.js 20）と npm を使用します。

```sh
npm ci
npm run dev
```

`npm run build` で TypeScript の型チェックと本番用ビルド、`npm run preview` でビルド結果の確認ができます。
キャッシュ保存先に書き込めない環境では `npm ci --cache /tmp/myhome-npm-cache` を使用してください。

## 現在の実装

React + TypeScript + Vite で、提供された Home Calendar UI のホーム画面とメニューを再現しています。
初期表示はデザインに合わせた 2026 年 1 月です。月切り替え、今日ボタン、日付選択、予定検索、カレンダー区分の表示切り替え、活動記録画面の表示、メニューの開閉に対応しています。

起動するとログイン画面を表示します。「Google でログイン」を押すとホームへ進み、アカウント欄の「ログアウト」でログイン画面に戻ります。認証は Supabase で別途実装する予定で、現在は認証を行わない表示確認用の動作です。

予定・ユーザー情報はサンプルです。Google 認証、データ保存、設定画面は未実装です。アカウント欄の「アイコンを変更」からイラストを選ぶかプロフィール画像をプレビューできますが、保存はされず、再読み込みすると元に戻ります。活動記録画面の内容は表示確認用のサンプルです。未実装のリンクは通知を表示します。
画像のカレンダーと右側の予定一覧にあった日付の不一致は、共通の予定データから描画して解消しています。

メニューの「引き継ぎ」から、Figma の役職一覧（12:2）に合わせたサンプル画面を開けます。代表・副代表・会計・合宿の4件を表示し、ホームへ戻れます。「合宿」から資料一覧（Figma 12:248）のサンプル5件を開き、資料名で検索し、役職一覧へ戻れます。すべての役職と新しく追加した役職から共通の資料一覧を開けます。資料がない役職は「資料はまだありません」と表示します。役職は画面内で一時追加でき、ホームに戻っても保持されますが、再読み込みで消えます。役職の削除、資料の編集・永続保存は未実装です。この一覧は画面確認用で、役職機能全体の採用や仕様を確定するものではありません。


- 資料は src/handoverDocuments.ts の型と初期サンプルを使い、main.tsx のメモリ内で役職ID別に保持します。全役職（追加役職を含む）の資料一覧でタイトル・本文を入力して一時作成し、src/DocumentPage.tsx の共通本文画面を開けます。ホームや役職一覧へ戻っても保持し、再読み込みで消えます。本文はプレーンテキストとして改行を保って表示し、編集・共有・永続保存は未実装です。
