## 開発

Node.js 22.12 以上（または 20.19 以上の Node.js 20）と npm を使用します。

```sh
npm ci
npm run dev
```

`npm run build` で TypeScript の型チェックと本番用ビルド、`npm run preview` でビルド結果の確認ができます。
キャッシュ保存先に書き込めない環境では `npm ci --cache /tmp/myhome-npm-cache` を使用してください。

## 現在の実装

React + TypeScript + Vite で、提供された Home Calendar UI のホーム画面とメニューを再現しています。
初期表示はデザインに合わせた 2026 年 1 月です。月切り替え、今日ボタン、日付選択、予定検索、カレンダー区分の表示切り替え、予定の追加・編集、活動記録画面の表示、メニューの開閉に対応しています。予定の追加・編集内容は画面内だけに保持され、再読み込みするとサンプルに戻ります。

Supabase AuthでGoogleログインし、セッションがある場合はホーム、未ログインの場合はログイン画面を表示します。ログアウトはこのブラウザのセッションを終了します。ルートの.env.localにVITE_SUPABASE_URLとVITE_SUPABASE_PUBLISHABLE_KEYを設定してください。Googleプロバイダーと開発URLの許可設定も必要です。

`supabase/migrations/20261018074616_create_circle_calendar_backend.sql` にサークル・所属・予定テーブルとRLSを定義し、Supabaseプロジェクト `myhome-dev` に適用しています。サークルメンバーは同じサークルの予定を読み込み・追加・編集できます。未所属ユーザーは予定を読めず、所属の登録は信頼された運営者が行います。ログイン済みで所属サークルが取得できる場合、ホーム画面はDBの予定を表示し、追加・編集をDBへ保存します。

`supabase/migrations/20261018090000_add_profile_activity_and_management.sql` でプロフィール、活動記録、予定削除、所属管理のテーブル・RLSも追加しています。プロフィールと活動記録の画面接続、予定削除UIは未実装です。

予定・ユーザー情報はサンプルを含みます。Google認証はSupabase Authに接続済みで、ホームのアカウント欄とメニューにログイン中のユーザーの名前・メールを表示します。未実装のリンクは通知を表示します。
画像のカレンダーと右側の予定一覧にあった日付の不一致は、共通の予定データから描画して解消しています。

メニューの「引き継ぎ」から、Figma の役職一覧（12:2）に合わせたサンプル画面を開けます。代表・副代表・会計・合宿の4件を表示し、ホームへ戻れます。「合宿」から資料一覧（Figma 12:248）のサンプル5件を開き、資料名で検索し、役職一覧へ戻れます。すべての役職と新しく追加した役職から共通の資料一覧を開けます。資料がない役職は「資料はまだありません」と表示します。役職は画面内で一時追加でき、ホームに戻っても保持されますが、再読み込みで消えます。役職の削除、資料の永続保存は未実装です。この一覧は画面確認用で、役職機能全体の採用や仕様を確定するものではありません。


- 資料は src/handoverDocuments.ts の型と初期サンプルを使い、main.tsx のメモリ内で役職ID別に保持します。全役職（追加役職を含む）の資料一覧でタイトル・本文を入力して一時作成し、src/DocumentPage.tsx の共通本文画面を開けます。ホームや役職一覧へ戻っても保持し、再読み込みで消えます。本文はプレーンテキストとして改行を保って表示し、共有・永続保存は未実装です。

- プロフィール設定は src/ProfileSettingsPage.tsx に実装しています。メニューとホームのアカウント欄から開き、表示名（空白除去後1〜50文字）、性別、学年を画面内で変更できます。性別・学年は未設定のままにもできます。メールアドレスはサンプルの読み取り専用表示です。変更内容は main.tsx の App で保持し、再読み込み・ログアウトで元に戻ります。プロフィールと認証ユーザーの連携、永続保存は未実装です。アイコン変更は別のサンプル機能で利用できます。

- プロフィールで役職を複数選択し、表示名と一緒に一時反映できます（管理者権限とは連動しません）。新規資料・活動記録にはサンプルユーザーIDと作成・更新日時を付け、本文で現在の表示名を解決します。既存サンプルの作成者は不明と表示し、編集時は更新者だけを付けます。日時は日本時間で表示します。プロフィールと認証ユーザーの連携・永続保存は未実装です。

- Supabase の接続設定がない場合は設定案内を表示します。開発時のみ「サンプル画面を確認」から認証なしのメモリ内UIを確認できます。本番ビルドではこの導線は表示しません。実際のログインには .env.local の VITE_SUPABASE_URL と VITE_SUPABASE_PUBLISHABLE_KEY をチームの設定に合わせて指定し、開発サーバーを再起動してください。

- 活動記録は詳細画面の「活動記録を削除」から確認ダイアログを経て削除できます。選んだ予定の活動内容・ふりかえり・作成者情報だけをメモリ内から削除し、カレンダーの予定や他の記録は残します。削除後は再作成できます。永続保存は未実装のため、初期サンプルの削除も再読み込みで元に戻ります。

- カレンダー・予定一覧から予定を開き、「予定を削除」で確認後、その予定と紐づく活動記録をメモリ内から削除できます。記録がない予定も削除できます。「活動記録を削除」は本文のみの削除です。どちらも永続保存はなく再読み込みで初期状態に戻ります。

- 全役職の引き継ぎ資料（初期サンプル・追加資料）を本文画面でタイトル・本文編集、確認付き削除できます。編集時は作成者を保持し、最終更新者・日時と一覧の更新日を更新します。削除後は検索条件を保った一覧に戻ります。変更・削除はメモリ内のみで、再読み込みすると初期状態に戻ります。

- カレンダー予定は年・月・日を保持し、表示月に一致する予定だけを表示します。DBからの取得は1月に限定せず、追加・編集の日付も選択年・月を使います。月切り替え・今日ボタンでは予定フォームを閉じ、別の月へ誤登録することを防ぎます。

- ユーザーの判断により、独立した「役職設定」はメニューから除外しています。引き継ぎ内の役職一覧・一時追加とプロフィールの役職選択は引き続き利用できます。
